# Day 5 – Python Functions

## What is a function?
A function is a reusable block of code that performs a specific task.

## Syntax
def function_name(parameters):
    code

## Why functions are important
- Avoid repetition
- Improve readability
- Make scripts reusable
- Used heavily in automation

## Example
def greet():
    print("Hello")

greet()

## Real-world use
Functions are used in monitoring, automation, and DevOps scripts.
